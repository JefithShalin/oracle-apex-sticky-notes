# Sticky Notes Widget Inside Oracle APEX

A modern Sticky Notes Widget built inside Oracle APEX using an HTML Static Region, CSS, JavaScript, and AJAX Callback processes.

This project allows users to create, move, edit, and manage sticky notes interactively while automatically saving notes into the database using Oracle APEX AJAX Callbacks.

---

## Features

- Create colorful sticky notes
- Drag and move notes freely
- Edit notes dynamically
- Auto-save notes to database
- Interactive notes board
- Responsive design
- Smooth UI experience
- No external plugins required

---

## Technologies Used

- Oracle APEX
- HTML Static Region
- CSS
- JavaScript
- AJAX Callback Process

---

## How It Works

- HTML Static Region is used to build the notes board layout
- CSS is used for sticky note styling and animations
- JavaScript handles note creation, dragging, editing, and interactions
- AJAX Callback Process saves and retrieves notes from the Oracle database dynamically
